PaperFills is the new product name. Current local testing builds may still display GhostTrade; this policy covers the same extension and data practices.

The short version

PaperFills is a paper-trading extension. Your simulated balances and trade history stay in this extension's local Chrome profile. The extension reads supported trading pages and requests public market data from DexScreener. There is no developer-run analytics or account server. PaperFills does not request wallet keys or submit real orders. Paper mode is not a guarantee against real trades through the host website: use a separate, unfunded practice account.

Terminal compatibility preview

This local preview also runs on trade.padre.gg (Terminal, formerly Padre). It reads visible trading controls, token identifiers, native select values containing public wallet addresses, wallet names, and displayed fees. It also reads the native chart price feed and passively observes allowlisted public Solana Trenches market subscriptions in Terminal's existing connection. The observer does not create a connection or send extra messages. From Terminal's existing settings-update subscription, a narrow projection reads only Solana buy/sell preset priority fees, tips, slippage tolerances, MEV settings and whether a custom RPC is configured. The custom RPC URL and unrelated settings values are skipped without decoding or retaining them. Authentication and transaction payloads are excluded. Bounded public token prices, related market fields and sanitized preset values are retained in page memory, not sent to a developer server. Terminal's paper settings and ledgers are stored separately from Axiom's. Public token addresses are sent to DexScreener for execution-price snapshots or independent SOL/USD rates; the extension does not send paper wallets or fills there. Re-reading a displayed price does not make it an executable live quote. Unindexed launches may be unavailable until a fresh quote is obtained. Unmapped native order types and shortcuts are blocked in paper mode. Terminal's website scripts can observe paper values, sanitized preset values and public feed diagnostics rendered into its DOM, and Terminal's own account/privacy practices remain separate. Turning Terminal paper mode off restores its native live controls. Use an unfunded practice account. This preview has not been released to the Chrome Web Store.

Terminal public trade events

To develop event-based paper exits, PaperFills passively reads the current Solana market's existing public trade subscription. It keeps a bounded in-page duplicate cache and projects transaction signatures, public maker addresses, trade indices, timestamps, buy/sell direction, and public price/amount fields. Initial history is not treated as a new trade. Stale, unknown and unrelated-market events are excluded. This does not read private wallet/tracked-trade feeds, create subscriptions, submit orders, or change your paper ledger by itself. Public diagnostics are visible to the site's scripts. Dev Sold remains blocked until developer identity and execution checks are implemented and verified.

Terminal shortcut settings

For automatic shortcut setup, PaperFills reads only Terminal's named saved preferences for shortcut bindings, wallet-group hotkeys and the Instant Trade hotkey switch. It cross-checks the bindings against Terminal's existing chart keyboard-configuration messages. It does not enumerate the site's storage or read authentication or signing-key records. The main ticket's full-address native selection also identifies the shared Instant Trade wallet selection; conflicting visible controls block paper execution.

Terminal wallet selection

To restore Trenches paper controls after reload, PaperFills reads only the named native preferences for the Trenches chain and selected wallet public addresses, using Terminal's local-storage or session-storage fallback. It requires Solana, known paper-wallet identities, an active native settings snapshot and a matching visible wallet count. An open native menu provides the checked-address selection directly. Empty, unknown or conflicting selections are not guessed from balances. No wallet keys or authentication records are read, and these preferences are not changed by PaperFills.

Terminal attached exits and presets

For Instant Trade TP/SL plans, PaperFills reads the visible native exit editor, or the single named saved exit-strategy preference when the main buy editor is hidden. It also reads the named selected-order-preset preference, cross-checks the displayed fees against the native preset snapshot, and saves separate buy and attached-sell fee settings with paper orders. Unsupported or incomplete exit rules are not silently discarded. These preferences contain trading configuration, not authentication or wallet secrets; the extension does not enumerate native storage or change the preferences itself.

Terminal performance diagnostics

The opt-in QA profiler also supports Terminal. It records bounded in-memory operation durations, quote ages, frame gaps, long-task durations and coarse browser heap sizes only after the user starts it. Reports exclude wallet identities, balances, token names, page URLs and order amounts. The profiler can display or download a JSON report when requested; it does not upload diagnostics or write them into the paper ledger. Held-token valuation on Trenches uses the same read-only public quote requests described below.

Axiom performance diagnostics

The troubleshooting profiler is off by default. When you explicitly enable and start it, bounded in-memory measurements record action types, selected-wallet counts, timing, frame gaps, long tasks and coarse page-memory usage. It does not collect wallet identifiers, balances, token identifiers or trade amounts. Reports are displayed or downloaded only on request, are not uploaded by PaperFills, and are not saved into the paper ledger. Page scripts can observe a report you display in Axiom's page. Reloading the page clears the in-memory report.

1. Data used to run paper trading

On axiom.trade, PaperFills reads the current route and token/pair identifiers, visible market information, trading controls, selected amounts, presets, fee settings, hotkey configuration, and relevant wallet/portfolio interface content. It uses this information to recognize paper-trade actions and display simulated balances, positions, orders, chart markers, and PnL. It does not request Chrome browsing-history access or inspect unrelated websites.

Paper markers, order levels and active-position totals are shared with the chart inside Axiom's page context. These displayed values and page-world messages can be observed by scripts running on that page. This is not an isolated wallet environment.

2. What is stored on your device

Chrome's extension-local storage holds simulation settings, paper balances, holdings, fills and timestamps, pending orders, funding adjustments, and cached Axiom presets/hotkeys and display preferences. Solana paper wallets are separated using locally stored Axiom wallet names and displayed public-address identifiers. PaperFills also reads public-address attributes on the native Wallets page to match rows. It does not request private keys. Older versions may have stored a separate Curve Lab session; the current extension no longer uses that data. PaperFills does not use Chrome storage sync to upload the ledger. JSON export creates a file only when you request it; import reads the backup you select.

Extension-local data is not separately encrypted by PaperFills. Anyone with access to your browser profile or exported backup may be able to read it. Use your operating system's account and disk protections, and do not put credentials or real wallet secrets in backups.

3. Market-data requests and third parties

PaperFills sends HTTPS GET requests to api.dexscreener.com containing the supported chain and public token or pair address needed for a quote, including a wrapped-native token address for an independent SOL/USD or ETH/USD lookup when needed. Requests omit browser credentials and do not attach your paper balance, trades, wallet keys, or backup. Like other web services, DexScreener receives ordinary connection information such as your IP address and request timing and may log it under its own practices. Pending paper orders can cause these lookups to continue while Chrome is running even when the trading tab is closed.

Axiom and Terminal independently process your use of their websites, including any login, cookies, wallet connections, or real trades. Their data practices are separate from PaperFills. Using the extension does not make your activity on those websites anonymous.

When you open a hosted copy of this policy, its hosting provider receives normal web-request information such as your IP address and request time. This page itself contains no analytics, advertising scripts, forms or third-party embeds.

4. Sharing and limited use

The extension contains no advertising, analytics beacon, data-sale feature, or developer-operated data-collection endpoint. The developer does not receive your local ledger through the extension. Data is used for the paper-trading features described here, not advertising, unrelated profiling, credit decisions, or lending. PaperFills does not sell user data. Public identifiers are transmitted to DexScreener only for the market-data feature. If you choose to send a support message or backup to someone, that is a separate disclosure you control.

5. Retention and deletion

Data persists across normal browser restarts in this installed extension's Chrome profile. Paper history retains up to 2,000 recent fills and 100 recent funding events per wallet ledger; older detail may be trimmed while aggregate balances and recorded transaction counts remain. New fills also retain position-lifecycle identifiers and cumulative totals so retained history can distinguish reopened positions. Older data may lack these totals and is not reconstructed.

A confirmed Solana reset clears all registered Solana paper-wallet ledgers for the selected platform, not just the primary wallet. It does not reset another platform or chain, cached preferences, wallet names, or legacy Curve Lab data. Retiring Curve Lab does not automatically erase its old stored session. Uninstalling the extension removes its extension-local data. Exported JSON files are not removed by reset or uninstall; delete those yourself if you no longer need them.

Switching paper mode off stops that platform's new scheduled paper fills, but restores its native live controls. For practice, use an unfunded account. To stop all extension activity, close supported trading tabs and disable or uninstall PaperFills. Because the developer does not receive your local ledger, deletion of that local data is performed on your device.

6. Permissions

Storage saves the local settings and paper ledgers described above. Alarms schedules pending-paper-order checks while Chrome runs. Site access is limited to axiom.trade, trade.padre.gg for the Terminal preview, and api.dexscreener.com for public quotes. PaperFills does not request access to all websites, your global browsing history, camera or microphone.
